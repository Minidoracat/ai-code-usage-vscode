# Support

Use GitHub Issues for bug reports, feature requests, and release questions:

https://github.com/minidoracat/ai-code-usage-vscode/issues

## Before Reporting a Bug

Please include:

- VS Code version
- Operating system
- Whether you are using local VS Code, Remote SSH, WSL, or another remote extension host
- Extension version
- The selected provider filter and date range
- A short description of what you expected and what happened

Do not paste real Claude Code or Codex usage JSON/JSONL into public issues. If a usage file shape is needed, reduce it to a synthetic example with fake session IDs, fake paths, and minimal token counts.

## Privacy-Sensitive Reports

If a report may contain private usage data, remove:

- Local usernames and home paths
- Session IDs
- Prompts or conversation content
- Token history that reveals real usage patterns
- Any API keys or tokens

Synthetic reproductions are preferred.
